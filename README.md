\# 🔥 Firebase Extractor Bot



Telegram bot that extracts Firebase configurations, API keys, and secrets from APK files.



\## Features

\- Extract Firebase URLs, API Keys, Project IDs, App IDs

\- Bulk APK processing (up to 20 APKs at once)

\- ZIP file support

\- Security vulnerability checking

\- JSON report generation



\## Commands

\- `/start` - Welcome message

\- `/help` - Help guide

\- `/bulk\_status` - Check bulk processing status



\## How to Use

1\. Send APK file(s) to the bot

2\. Wait for analysis

3\. Get detailed reports
